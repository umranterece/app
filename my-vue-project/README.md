# My Vue Project

This is a minimal Vue 3 project created with Vite. To run it locally:

```bash
npm install
npm run dev
```

Use `npm run build` to create a production build and `npm run preview` to preview the build.

## Agora Example

This project includes a simple demo using [Agora RTC Web SDK](https://www.agora.io/).
Update `src/components/AgoraDemo.vue` with your `APP_ID`, `TOKEN`, and `CHANNEL`
to try real-time video.
